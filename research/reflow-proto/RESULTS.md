# Fixed-box reflow research results

Generated by `bash research/reflow-proto/run.sh` on the pinned corpus. This is **layout/debug evidence, not an edited-PDF round trip, production acceptance rate, O0 run, or RegionProof**.

Engine: PDF metrics + HarfRust 0.16.0 + unicode-linebreak 0.1.5 + unicode-bidi 0.3.18. Six body paragraphs, 24 edits plus six identity controls. Geometric fit: **10/24 edits**; **14/24 do not fit**. These counts do not imply safe exports. Linux x86_64 stripped release executable: **1,810,448 bytes** (includes JSON CLI, shaping and diagnostic font parser; not incremental Tauri/Android size).

## Method and definitions

- Bounds and baseline slots were frozen from real source placements/ink **before** edits. No blank slots, box growth, font scaling or full justification. Indents are retained by the research slots; they fail the current strict §4.5 production subset.
- Chinese inserts/expansions use **fixed token index 8** (zero-based boundary after eight input tokens), which can split a word; this is not a linguistic phrase-boundary detector. Inserts add `在实际应用中`; exact joined snippets are quoted below. English inserts add `carefully ` after the first source/inferred space. Deletes remove `人工智能` or a first-line word. The table reports actual Unicode-scalar length change; +10/+30 use additional same-script prose, rounded to nearby English word boundaries.
- Unchanged source codes bypass shaping. Rust recalculates advances from PDF dictionary widths, Tf/Tc/Tw/Tz and the transformed basis; measured boundary gaps are retained when original neighbours remain together. **The near-zero PDF advance error is an adapter consistency check, not an independent oracle.** Source offsets and native PDFium origins are recorded separately.
- Baseline drift compares output lines in retained source slots with original baselines; it is zero by construction on this fixed grid. It says nothing about x drift, moved glyph correctness or spacing between ink envelopes. Overflow lines are counted but have **null origins**: no unauthorised baseline is invented.
- Verified embedded TrueType code→GID mappings remain usable even when a subset Unicode cmap cannot shape the text. New source-coded clusters use `/W` or `/Widths`; unavailable/new glyphs use Noto SC or the existing Liberation Serif TTF, with HarfRust shaping. Raw Type1 bytes are extracted but **not parsed**. A fallback advance is a program metric in this spike; an emitted subset dictionary/permission proof is still required before production use.
- English **inferred gap spaces** use the heuristic `gap > 0.12 * size`; inferred soft joins add `0.25 * size` (0.25 em) when the source line does not end in `-`. These spaces are not manually reviewed/reconstructed. They have no source/code/GID/native-origin/Unicode proof; only style and diagnostic geometry remain. Literal source hyphens are retained without dehyphenation. Unknown Unicode uses native labels where available and remains unproven. No inferred whitespace, unknown font mapping, interleaved operators, multi-BT content, or geometry-only manual region is certified safe by this runner.
- `extract.ts` applies a manual glyph-origin x filter: it drops `arxiv-2611.17030` glyphs with `x > 300 pt` and `arxiv-2611.17053` glyphs with `x > 310 pt` before grouping left-column lines. These are fixed research column clips, not a proven column detector or PDF clip; kept glyph ink can extend beyond the threshold. Excluded glyph counts are recorded in `samples.json`.
- Every edit note carries the sample identity-control native source x maximum. The legacy `native_stationary_x_max` field is labelled by `native_comparison_scope`: inserts/expansions compare only the unmoved prefix (`prefix-only`); identity/deletion compare remaining source glyphs. A small prefix figure does not replace the full identity-control failure.
- The wider UAX14 candidate set is diagnostic; production still intersects the §4.6 Latin-space/plain-Han whitelist. The prototype does not perform the TS spacing/suffix-shift cascade, validate all obstacles/semantic scopes, prevent every TJ-kern split, compile Tj/TJ or validate rejoin Tlm. Ordinary deletion preserves all remaining source glyph positions and intentional gaps.

## Decision and remaining gates

The measured-cluster design preserves dictionary advances while allowing a small exact slot breaker. General paragraph typography is unnecessary for this scope; the source/font/TJ proof is the hard part. The actual +30% cases overflow, and some short inserts fit, without changing the box. This supports the interface choice, not a forecast.

Still required before production: validated RegionProof/obstacles/semantics/single-BT ownership; source whitespace/Unicode round trips; native-width disagreement resolution; complete mandatory break/kern guards; fallback permission/subset dictionary metrics; Type1 F5; actual TS↔Rust codec/platform builds; R8 Tj/TJ surgery and rejoin; O1b native before/after PDFs and raster/extraction gates. Nothing in this spike changes the default-off policy.

Verification is the complete six-paragraph/30-case run plus independent source/native comparisons, Cargo fmt and clippy. See [README](README.md) for the single regeneration command, dependencies, failure history and exact artifact semantics.
