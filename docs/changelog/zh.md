# 更新日志

## 未发布

### 开源

- **Shiori 和 Shiori CLI 开源了。** 全部源代码以 MIT 许可证公开在 github.com/Nagi-ovo/shiori，可以自由查看、使用和修改，也欢迎在那里反馈问题。

### 加密 PDF

- **加了密码的 PDF 也能导出修改了，导出后密码还在。** 以前导出时会让你先用别的工具去掉密码；现在导出的文件和原文件用同一个密码打开，原文件对打印、修改、加批注的限制也照旧保留。
- **加了密码的 PDF 也能插入页面、能打印了。** 原文件不允许打印时，会直接告诉你。

### 缩放与翻页

- **触控板捏合缩放不会再卡在半路。** 以前偶尔松手后页面停在预览状态，要再缩放一次才落定。
- **在页面上按一下，不会再把它拉到顶部。** 以前按在下一页露出的那一截上，整页会突然滚上来。
- **重新打开 PDF，会回到上次那一页的开头。** 以前可能偏出好几百像素。
- **键盘和菜单的放大缩小，跟工具栏走同一组档位。** 比如从 150% 缩小，依次是 125%、110%、100%。
- **弹窗打开时，按键不会再作用到后面的文档。** 以前开着快捷键说明按 Delete，会删掉后面选中的批注。

### 界面

- **拖动标签页换位置时，整张标签一起移动。** 以前标签文字会被拉宽、变淡，还可能拖出标签栏。

### 界面

- **选中的标签和下面的工具栏连成一体了。** 以前标签像贴在工具栏上的一块，现在它和工具栏是同一块面，底角圆润地过渡到标签栏。

- **在 Markdown 的阅读和编辑之间切换，停在原来读到的地方。** 以前切换后会跳到别的段落。
- **旋转过的 PDF 页面可以正常选字了。**
- **PDF 里的「下一页」「上一页」链接能点了**，幻灯片导出的 PDF 常用这种按钮。

- **「编辑将覆盖暂存草稿」的提示可以关掉了**，草稿继续保留，下次编辑时再问。
- **关闭标签时不再闪一下首页。**

  或文件无法安全复制时，Shiori 会保持当前文档不变并说明原因。
- **编辑后完整导出 PDF，附件不会再静默消失。** 只属于已删除页面的文件会随页面
  移除。只导出部分页面时仍会为保护隐私省略附件；「压缩」实际生成图片页时，会
  保留整份 PDF 的附件，但不包含只挂在页面上的文件。

### 移动端阅读

- **超宽 Word 页面现在会完整收进屏幕。** 横向页面、非常规大纸张和宽表格不会再
  越出白纸与手机视口；常见的中日文无衬线字体也会按实际显示字体计算换行。
- **手机和平板上的标签可以自然横向滑动。** 左右滑动即可找到所有打开的文档，
  长按后才进入拖动排序；“+”固定留在旁边，不会跟着标签滑走。

### 界面与性能

### 工作区

- **文档、页面、标记和挂载文件夹现在都在同一个导航器里。** 正文拿回更多空间，
  文件夹里的资料也能直接留在手边，不用逐个打开。
- **同时打开几十份文档，标签工作区也不会越用越重。** Shiori 只让当前需要的
  文档留在内存里，其余文档会暂时休息；回来时，编辑、撤销记录和阅读位置都还在。
- **隐藏标签终于可以顺手管理了。** “+N”菜单会跟随当前主题，连续关闭多个标签时
  不会消失，也可以一次关闭全部隐藏标签；悬浮或键盘聚焦时，还能先看上次读到的
  页面。左侧导航器也提供同样的快速预览。

### 阅读与编辑

- **现在可以直接在 Shiori 里阅读 Word 文档。** Word 文件会进入最近文件和工作区，
  记住缩放与滚动位置，并能从桌面、网页和移动端的原有入口打开。
- **PDF、Word、Markdown 和 HTML 的缩放都更跟手了。** 页面会稳稳留在手指或
  光标下方，不再闪白，也不会在手势的每一步都重新排版整份文档。
- **不同格式共用同一套清楚、稳定的界面。** 导航与工具不会因为文件格式改变而
  跳位，暂时用不了的操作会留在原处并变灰；图标、滚动条、焦点状态和拖拽操作也
  重新统一成一个完整的工作区。

### 修复

- **删除页面后，不会再留下点不动又说不清原因的大纲。** 失效条目会说明目标页面
  已不存在，导出的 PDF 也会清理失效大纲、打开动作和页内跳转链接。
- **追加图片页和重新打开文档更可靠了。** 链接与已填写的表单不会消失；连续粘贴
  不会互相取消或落进另一份文档；已经导出或恢复的文档，也会保留离开时的状态。
- **一次打开多份文档更可靠了。** 其中一份无法读取，不会连累其余选择；加载途中
  切到别的标签后，文件仍会在后台打开，但不会突然抢回当前画面。

## 26.7.27

### 新增
- **Shiori 命令行工具，可以给「正在 Shiori 里打开的那份 PDF」写批注。** 命令行和 AI 助手能直接对当前打开的文档做高亮、下划线、便签，不用先导出再导回来，写入过程在屏幕上实时可见。
- **批注可以用原文定位，不用算坐标。** 写下要标注的那句话，Shiori 自己在文档里找到它并算好位置；找不到或找到多处时会列出候选页码，而不是瞎猜。中文同样支持。
- **扫描页和图表可以渲染成图片。** 没有文字层的页面，命令行可以把它渲染成 PNG，让只能读文本的工具也能「看见」这一页。
- **命令行写入的批注按人类节奏一笔笔画出来。** 不是瞬间蹦出来，而是按书写轨迹分批绘制，每一批都能单独撤销。
- **可以在系统自带的终端里打开当前目录。** 会记住你上次选的终端 App，图标也用它自己的。
- **Markdown 编辑可以存回原文件了。** 此前编辑只写进 Shiori 的本地副本，磁盘上的文件原封不动、界面也没提示。现在 ⌘S（或有未保存修改时出现的保存按钮）直接写回来源文件。
- **Markdown 阅读外观可调。** 正文字体、代码字体、标题颜色、字号、行高、内容宽度都能自己设。
- **主题色和纸张颜色可以自定义，新增 Everforest 纸色。** 两者都会自动保证对比度安全。
- **Windows / Linux 有了原生菜单栏。** 此前只有 macOS 有菜单，其余平台所有快捷键都只挂在网页层。
- **窗口大小和位置会跨启动记住。** 不再每次都跳回默认尺寸。
- **批注可以收起了。** 收起后是一枚小圆印章，用批注自己的颜色，中间是批注的第一个字；点一下就展开。收起只是阅读时的样子，导出的 PDF 里永远是完整的批注卡片。
- **单击页面任意位置就能写批注。** 不只是选中文字——图表、公式、扫描件这些没有文字层的地方，点哪儿批注就指哪儿。

### 改进
- **工具栏重新分组。** 矩形并入「绘制」（和画笔一组）、签名和印章并入「签章」、便签工具下架、批注工具改名为朴素的「批注」。
- **拖选文字时，选区直接显示成工具将要用的颜色。** 不用松手才知道高亮是什么色。
- **批注框不再压在正文上。** 新建批注时会读取整页正文的位置，自动落在留白处，优先贴在被批注那行旁边的页边空白。
- **批注框会贴着页边变窄、跟着文字长高。** 正好塞进页边留白不压字；写多少字就有多高，不再写着写着被裁掉。
- **选中标注时四角的手柄换成了更安静的圆点。**
- **签名板有了签名引导线，清除 / 保存按钮换到更顺手的位置。** 空白的签名板上有一条淡淡的横线提示「在这儿签」，落笔就消失。
- **收起的便签更稳。** 可以直接拖动而不会误展开，折叠状态在旋转页面和重新打开后都保留，键盘和读屏也能操作。
- **界面本身不再会被误选中。** 缩略图栏不再被卷进 PDF 的文字选区，阅读区不再弹出浏览器右键菜单，键盘操作有统一的焦点框。
- **内嵌终端不再限制窗口能缩到多小。** 以前是窗口不能小于终端，现在终端自己让位。
- **安全加固。** 应用命令只允许可信页面调用，并升级了有漏洞的文档解析依赖。

### 修复
- **旋转 90° / 270° 的页面上，标注位置偏 180°。** 文件自带旋转的页面（扫描件、横版）一打开标注就在错的位置；在应用内旋转后画的标注屏幕上看着对，导出后偏 180°。
- **导出可能静默丢掉源 PDF 的一部分。** 尤其是加密来源的文件：导出看起来成功、页数也对，磁盘上的文件其实已经坏了。
- **Shiori 不能编辑的批注不再从屏幕上消失。** 别的软件画的箭头、椭圆、多边形、图章、附件、表单域，以前打开时看不见（文件里其实还在），现在会正常显示。
- **批注在导入导出往返后保持原样。** 文字批注的样式和控件不再丢失。
- **草稿在特定崩溃时机不再丢失。** 修好后的自动保存不会再把唯一的那份恢复记录当成过期数据清掉。
- **多标签的状态跨导航和重启保持正确。**
- **手势和按键不会再提交你没做过的编辑。**
- **在桌面对话框里选中多个文件时，会全部打开**，不再只开第一个。
- **macOS 菜单栏跟随语言显示。** 桌面端保存 PDF 改为原子写入，中断不会留下半个文件。
- **补齐了一批仍以英文显示的界面文字。**
- **拖动四角改批注框大小时不跟手了。** 卡片会慢半拍地追着指针走，引线却跟得很紧，两者脱节；现在改大小是即时的。
- **签名对话框的按钮对齐，以及官网的导航、打印和无障碍问题。**

## 0.1.25 · 2026-07-07

### 新增
- **整段编辑原文。** 文字工具下单击一个段落，整段变成编辑框（保持原行距、行首位置），像 PDF Expert 一样直接改整段。图表、公式段落会自动跳过并提示原因，仍可用拖选做局部编辑。
- **撤销历史跨会话保留。** 草稿连同最近 50 步编辑历史一起保存，关掉 app 再打开同一个 PDF，恢复后仍能一步步撤销。

### 改进
- **编辑原文的字体保真。** 编辑框直接用文档内嵌的原字体显示，编辑中、完成后、导出三处完全一致；导出尽量用原字体书写，字体缺字时回退到与 Times/Helvetica/Courier 等宽的内置字体，排版宽度不变。
- **编辑原文时提前预警。** 替换文字超出原文宽度、或含原字体没有的字符时，编辑框下方实时提示，不必等导出才发现。
- **工具栏图标统一了视觉规格。** 统一描边粗细、圆角和光学尺寸，整排更安静整齐。
- **缩略图里的密集笔迹不再糊成一团。** 被放大的细笔画按比例变半透明，写满批注的页面在缩略图里仍可读。
