# 更新情報

## 26.10.23

> 唯我独尊

### 書き出し

- **一部のページだけを書き出したとき、選んでいないページが混ざらなくなりました。** これまでは PDF によって、1 ページだけ書き出しても他のページの内容がファイルに残ることがありました。
- **書き出し後も、既定で非表示のレイヤーは非表示のまま、フォームの自動計算もそのまま動きます。** 問題集の解答レイヤーが書き出しや印刷で表に出ることはもうありません。右開きの本の綴じ方向や見開き表示も保たれます。
- **回転させたテキストボックス、スタンプ、四角形、署名、画像が、書き出し後も同じ角度のまま残ります。** サイドバーのサムネイルと「小さいファイル」書き出しでも同じです。
- **「小さいファイル」書き出しで、画像や署名、文書のタイトルと作成者が失われなくなりました。** 配置した画像や署名はサイドバーのサムネイルにも表示されます。
- **元の文字を修正して書き出すと、古い文字がページの内容から取り除かれます。** まれに取り除けない場合は、書き出す前にお知らせします。古い文字は隠れていても、検索やコピーで取り出せてしまうためです。

### 注釈の読み込みと書き出し

- **Zotero、プレビュー、Acrobat で付けた注釈のコメントが、書き出しで消えなくなりました。** ハイライト、下線、取り消し線、四角形、手書きに付いたコメントがすべて残ります。
- **非表示・ロック・印刷しない設定の注釈は、書き出し後もそのままです。** 非表示の注釈が表に出ることはなくなり、付箋のアイコン、開閉状態、レビュー状態、回転の角度も保たれます。
- **ほかのアプリで作ったテキストボックスや半透明の注釈が、元と同じ見た目になりました。** テキストボックスの背景色・枠線・不透明度が画面にも書き出しにも反映され、半透明の手書き、四角形、下線、取り消し線が不透明になることもありません。
- **注釈の作成者と返信が、書き出し後もそのまま残ります。** 日本語や中国語などの作成者名が文字化けしなくなり、返信も元の注釈にぶら下がったままです。
- **読み込んだ注釈の位置、色、向きがより正確になりました。** ページ構造が特殊な PDF でも別のページに付かなくなり、四角形の塗りが消えたり、一部の色がずれたりすることもなくなりました。回転したページのテキスト注釈も横倒しになりません。

### 編集

- **ある PDF でコピーした注釈を、別のタブに貼り付けられるようになりました。** Cmd+D で手書きの線を複製すると、コピーは少しずらして置かれ、元の線にぴったり重なることはなくなりました。
- **取り消しの履歴がすっきりしました。** カラーピッカーのドラッグは 1 回分として記録され、ロックされた注釈で Delete や矢印キーを押しても空の履歴が残りません。取り消しややり直しで、選択中の文字が外れることもなくなりました。
- **2 段組みのページでも、段落をクリックして元の文字を直接修正できるようになりました。** 結合した PDF で元の文字を修正しても、フォントを取り違えなくなりました。
- **ボタン、サムネイル欄、タブにフォーカスがあるときは、矢印キー、Space、Enter がそちらで処理されます。** これまでは矢印キーで選択中の注釈が動いていました。

### 検索と文字

- **行の折り返しで分かれた語句も見つかるようになりました。** 行をまたぐ日本語や中国語のフレーズ、ハイフンで行をまたいだ単語も検索できます。検索結果が別の段や段落にまたがったり、絵文字やアクセント付きの文字、ヘブライ語・アラビア語・タイ語・ヒンディー語などの文字の途中で切れたりすることもなくなりました。
- **ヘブライ語やアラビア語など右から左に書く文字や、回転した文字も、正しく検索・選択できるようになりました。** これまでは単語の途中に余計なスペースや改行が入っていました。

### 閲覧とページ

- **ウィンドウを別の画面に移すと、その画面の解像度でページが描き直されます。** 拡大・縮小やウィンドウのサイズ変更を続けても、ページはくっきりしたままです。
- **ページサイズの書き方が特殊な PDF も、正しい大きさで表示されるようになりました。** たとえば A4 の文書が Letter として扱われることがありました。
- **ページの挿入や画像の貼り付けを受け付ける PDF が増えました。** ほかのツールで編集された PDF や、空のフォームを持つ PDF はよく拒否されていました。挿入したページが、スクリーンリーダーで元の文書の段落と取り違えられることもなくなりました。

### Markdown とテキストファイル

- **ほかのエディタでファイルが変更されていたら、Cmd+S で黙って上書きせず、先に確認します。**
- **UTF-8 以外のファイルは読み取り専用で開くので、保存で文字化けすることはありません。** 保存時には元の改行コードと BOM も保たれ、Windows で書かれたファイルを 1 文字直しただけで全行が書き換わることもなくなりました。CRLF 改行の Markdown をプレビューと編集で切り替えたあとに元に戻しても、改行コードが変わりません。
- **Markdown のプレビューがより確かになりました。** 「---」の区切り線で始まる文書の最初の節が消えなくなり、ページ内リンクと目次は該当箇所までスクロールします。ファイル名に % を含むローカル画像も表示されます。
- **タブを切り替えるときにテキストの変更を保存できなかったら、黙ってとどまらずにお知らせします。**

### 下書きと復元

- **自動の整理で、開いている文書が消えなくなりました。** 保存領域が足りなくなっても、開いているタブ（ほかのウィンドウのものも含む）の注釈の下書きは守られます。複数の PDF を一度にドロップしたときや、パスワード入力を待っている間も、開いている途中の文書が失われません。
- **内容が同じで置き場所の違う 2 つの PDF は、それぞれ自分の注釈を保存します。** 以前はこうした 2 つを同時に編集すると、再起動後に片方の注釈が消えていました。元に戻しきった直後にページを閉じても、取り消した注釈がまれに復活することはなくなりました。
- **同じファイルを 2 つのウィンドウで編集しても、互いの変更を上書きしなくなりました。** 後から保存したウィンドウでは、閉じる前に変更を書き出すか破棄するかを選べます。Web 版でこのタブを閉じたり再読み込みしたりすると、先に確認します。
- **Web 版のタブを閉じる直前の変更も保存され、開き直しても取り消しの履歴が残ります。**

### Web 版

- **Chrome と Edge で、複数のファイルを一度に開けるようになりました。** Safari で書き出したファイルのダウンロードがときどき失敗することもなくなりました。

### セキュリティ

- **HTML 文書の実行と Markdown プレビューの隔離を強化しました。** 悪意のあるファイルに悪用されうる問題をいくつか修正し、「リモート画像を読み込まない」設定がより多くの場合に効くようになりました。デスクトップ版で HTML を実行するときの許可の案内には、実際に許可できる項目だけが並びます。実行モードでは、宣言的 Shadow DOM で書かれた内容の一部を表示しなくなりました。
- **壊れた PDF や細工された PDF、特定のパスワードで、アプリが落ちなくなりました。** Web 版とモバイル版では、開くのに失敗したあとメモリを占有し続けることもなくなりました。

### ブラウザパネル

- **ページがメール、電話、メッセージ、地図などほかのアプリを開こうとすると、先に確認します。**
- **戻るボタンとアドレスバーがより正確になりました。** リンクを行き来したあとに戻るボタンが無効になることはなくなり、ページ内の小さなフレームがアドレスバーや履歴を書き換えることもなくなりました。ページが自分で戻る・進む・アドレスだけを変える場合も、ボタンとアドレスバーが追従します。
- **Mac でページのダイアログが表示されるようになりました。iPhone と iPad でも、新しいウィンドウで開くリンクとページのダイアログが使えます。** Android の「一時セッション」が保存済みのログインと混ざることもなくなりました。システムの WebView が分離に対応していない場合は、その旨をお知らせします。

### ターミナル

- **内蔵ターミナルに長いテキストを貼り付けても、アプリ全体が固まらなくなりました。** ターミナルを閉じると、バックグラウンドで動いているプログラムも一緒に終了します。
- **フォルダ名に空白や特殊な文字があっても、内蔵ターミナルと外部ターミナルが正しい場所で開きます。** Windows の内蔵ターミナルで cmd を使うときも、`start` で開いた URL がブラウザパネルに表示されます。

### デスクトップ

- **Windows で設定を開いている間も、右上の最小化・最大化・閉じるボタンを押せます。**
- **Linux でファイルやリンクをシステムのアプリで開いても、Shiori が固まらなくなりました。** 保存時の一時ファイルの扱いもより安全になり、名前がとても長いファイルも普通に保存できます。
- **macOS のリソースパネルが Web コンテンツのプロセスも数えるようになり、メモリと CPU の数字が実態に近くなりました。** メニューの「Shiori について」も表示言語に合わせて切り替わります。

### Android と iOS

- **Android でリンクやテキストを Shiori に共有すると、Markdown 文書として開きます。**
- **Android の直接アップデートで、インストールの失敗やキャンセルをお知らせするようになりました。** システムのインストーラに渡ったあとはアップデートの画面を閉じられます。履歴から Shiori に戻ったときに、古いファイルを開き直したり権限エラーが出たりすることもなくなりました。
- **Android と iOS で、ファイルとして受け取るもの・共有するものの範囲を絞りました。**

### アクセシビリティとインターフェース

- **スクリーンリーダーが読み上げられる名前が増えました。** 四角形、画像、署名、元の文字の修正といった注釈が英語の識別子で読まれなくなり、書き出し範囲、アドレスバー、テキストボックスの編集欄に名前が付きました。下書き一覧の削除ボタンは、それぞれ対象のファイル名を読み上げます。
- **ダイアログと設定でのフォーカスの扱いが整いました。** 設定を開いている間は後ろのページにキーボードが届かず、読み込みに時間のかかったダイアログを閉じると元のボタンにフォーカスが戻ります。ダイアログを開いていても通知はクリックでき、ダークテーマでも書き出し時の画質の注意が読みやすくなりました。

### コマンドライン

- **CLI のインストールがより確実になりました。** Windows で PowerShell からインストールしたあと、どのフォルダからでも PDF を扱えます。npm のインストールが途中で止まっても半端なバージョンが残らず、パイプでのインストールが途中で失敗したときは成功と表示せずにエラーを報告します。
- **search と extract がより正確で、より頑丈になりました。** 検索結果の枠が正しい文字に重なり、注釈の多い大きなファイルでも extract が止まりません。Word ファイルはすぐに非対応と伝えます。
- **app annotate がより確実になりました。** 文書に空の返信があったり、1 つの注釈に複数の返信を付けたりしても失敗しません。アプリを再起動しても見つけ直せます。同じ注釈を `--nonce` でもう一度適用でき、「-」で始まるオプション値には `--name=value` の書き方を案内します。

- **トラックパッドのピンチ操作が途中で止まらなくなりました。** これまでは指を離したあともプレビューのままになり、もう一度拡大・縮小するまで確定しないことがありました。

- **キーボードとメニューの拡大・縮小が、ツールバーと同じ段階で動くようになりました。** たとえば 150% から縮小すると 125%、110%、100% と進みます。
