# Security policy

## Supported versions

Only the latest release receives security fixes. Please check that a problem
still reproduces on it before reporting.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose **Report a
vulnerability**. Please do not open a public issue, discussion or pull request
for a security problem.

Include what you can: the affected version and platform (web, macOS, Windows,
Linux, Android, or the CLI), steps or a file that reproduces the problem, and
the impact you expect. Replies come in the private advisory thread.

Shiori is maintained by one person and has no bug bounty program.
